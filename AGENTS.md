# fec-reconcile, notes for agents

Project rules: `~/memolabs/AGENTS.md`. This file only adds what is specific here.

## Layout

- `backend/`: Java 17, Spring Boot 4.2, Maven wrapper. The comparison logic lives in
  `dev.memolabs.fec.core` and has no Spring dependency; `web/` only exposes it.
- `frontend/`: Angular 22, generated by the official CLI. Its own `CLAUDE.md` holds the Angular
  rules from the Angular team; follow them.
- `samples/`: fictional FEC files, rebuilt by `python3 samples/make_samples.py`. Copies for the
  demo button live in `frontend/public/exemple/`; regenerate both together.

## Checks before a commit

```bash
cd backend && ./mvnw test
cd frontend && npx ng lint && npx ng test --watch=false && npx ng build
```

## Rules

- Never commit a real FEC: it is a company's whole accounting. Only fictional files in `samples/`.
- The API stays bound to 127.0.0.1 and never stores or logs file content.
- Format questions are settled by article A47 A-1 of the LPF and BOFiP BOI-CF-IOR-60-40-20, not
  by memory. Cite the paragraph in the code when a rule comes from them.
- Skills for this repo are in `.claude/skills/` (sources in `.claude/skills/SOURCES.md`). The
  Angular CLI MCP server is declared in `.mcp.json`.
